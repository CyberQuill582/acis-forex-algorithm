The guard-integrity spirit (§9: "a guardrail a guarded process can reach is not a guard") applies to the layer law too: a law enforced only by an import-linter, with a spec-sanctioned shared-object side channel the linter cannot see, is reachable.
- Justification: ACIS-13 must forbid the shared session object from carrying any state upward — either the two faces share only a transport/auth handle (no account or position state readable by the feed face), or the shared object is split so the feed face physically cannot reach execution/account fields, plus a runtime/contract test that asserts the feed face never reads account state (not just that it doesn't import upward). Architectural — human/deep-spec owned.
